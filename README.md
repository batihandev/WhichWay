## WhichWay

A minimal hyper-casual Android game about focus and reaction speed, built in Unity.

Four arrows each point a different way. Tap the left or right side of the screen and every arrow moves in the direction it faces. Guide them into the right portals to score.

- Leaderboards through Google Play Games
- Optional rewarded ads through AdMob

👉 [Play on Google Play](https://play.google.com/store/apps/details?id=com.VexeDev.WhichWay)
